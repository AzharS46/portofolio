# Custom Project Rules

- **Git Commit Messages**: Selalu gunakan Bahasa Indonesia santai / tidak baku saat menulis pesan commit (contoh: `git commit -m "update tampilan mathnusa"`, `git commit -m "benerin bug di halaman contact"`, dll).
- **Gaya Komunikasi**: Gunakan bahasa Indonesia santai, ramah, dan tidak kaku dalam setiap respon.
